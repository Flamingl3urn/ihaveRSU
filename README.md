# คำสั่งถ้าทำการเปลี่ยนแปลงกับโค้ด
- git add .
- git commit -m "เพิ่มอะไรหรือแก้ไขอะไรโค้ดแล้วบ้าง"
- git push

# คำสั่งถ้าจะดึงโค้ดมาทำ (ทำทุกครั้งหลังเข้ามา)
- git pull

- เข้ามาแล้วอย่าลืม cd frontend/backend แล้ว **npm install**
